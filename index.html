Claude Haiku 5.5 發布：API 費率較前代降 50%，為 Anthropic 最快模型
Anthropic launches Claude Haiku 5.5 with 90% API price reduction
Anthropic 於 10 月 7 日發布 Claude Haiku 5.5，定價 $0.10/$0.50 per million 輸入/輸出 tokens（100K 以下），較 Haiku 4.5 降 50%；整體工作負載估計節省約 75% 成本。支援 1M token 上下文、128K 輸出，速度達 183 tokens/s，首次新增可調 effort 設定（low/medium/high）。
對你的意義對你的意義：高量摘要、玩家回饋分類、遊戲日誌分析等批次處理場景成本驟降；若現有流程以 Haiku 4.5 或 GPT-6 Luna 處理大批量任務，切換 Haiku 5.5 可直接節省可觀 API 預算。1M 上下文也讓單次載入完整遊戲腳本或長期記憶成為可能。
